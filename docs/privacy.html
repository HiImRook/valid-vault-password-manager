Privacy Policy

Last updated: August 2026

Scope

This Privacy Policy describes how the Valid Vault browser extension and Android application handle information. Both are built from the same source code and are governed by this policy.

Information We Collect

Valid Vault does not collect any information. The application has no servers, no backend, and no user accounts. It does not use analytics or telemetry, and it does not transmit information to the developer or to any third party.

Information Stored on Your Device

To function as a password manager, Valid Vault stores the following on your device in encrypted form:

  • Credentials you save, including site, username, and password
  • Your selected unlock method, such as fingerprint (WebAuthn), PIN, or password
  • Application settings

This data is stored locally, in your browser's local storage or your device's application storage. It is not transmitted to the developer or any third party.

Permissions

The browser extension requests the following permissions solely to operate as a password manager. Each permission is used locally on your device and is not used to collect or transmit information:

  • Host access: to detect login forms on websites you visit and fill saved credentials into them. Page content is not collected or transmitted.
  • activeTab: to read the domain of the current page so the matching saved credentials can be offered.
  • Storage: to store the encrypted vault and application settings locally on your device.

Device-to-Device Sync

Valid Vault allows credentials to be moved between a user's own devices using QR codes. One device displays data as a QR code and another device scans it. This transfer occurs directly between the devices and does not involve a server or any external service.

Third Parties

Valid Vault does not share information with third parties. It contains no advertising, no analytics providers, and no external services that receive user information.

Data Retention and Deletion

All data is stored on your device and remains under your control. You may clear the vault within the application's settings, or remove the extension or uninstall the application to delete its stored data from your device.

Children's Privacy

Valid Vault is a general-purpose application and is not directed at children. It does not collect personal information from any user.

Changes to This Policy

Any changes to this policy will be posted on this page with an updated date.

Contact

Valid Vault is an open-source project maintained by Rook. Source code and contact options are available on GitHub.
